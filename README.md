# Skinstric AI Analysis

Skinstric AI Analysis is a multi-step React interface for a skincare/demographic analysis flow. It guides users through identity capture, image input, API submission, loading states, and confidence-based results.

Live demo: https://figma-ashy-psi.vercel.app

## Features

- Multi-step product flow with clear back/next navigation.
- Typed identity capture for name and location.
- Camera and gallery image input paths.
- API submission flow with loading and response states.
- Demographic result cards with confidence scoring.
- Responsive styling for desktop and mobile layouts.

## Stack

- React
- Vite
- TypeScript dependency setup
- JavaScript/JSX
- CSS
- Vercel

## What This Shows

- Frontend state management across a multi-screen workflow.
- Browser API usage for camera and file-upload interactions.
- Async request handling with user-visible loading feedback.
- Product-detail polish in a realistic interactive flow.
